# AI Prompt Generator

A complete, simple, and Blogger-friendly AI prompt generator tool.

## Features
- Generates customized prompts for any topic
- Works for blog writing, SEO, social media, coding, business, marketing, study, and more
- Includes tone, audience, language, format, and length settings
- Copy button for quick use
- Reset button for starting fresh
- Clean responsive design
- Fully front-end and easy to paste into Blogger

## Files
- `index.html` – complete tool UI and logic

## How to use in Blogger
1. Open your Blogger dashboard.
2. Go to the page or section where you want to add the tool.
3. Use the HTML/JavaScript editor or Add HTML gadget.
4. Copy the full contents of `index.html` and paste it there.
5. Save and publish.

## Important Note
This tool runs directly in the browser. It does not require a backend or API key.
