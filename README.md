# AI Prompt Generator Pro

A premium-style, Blogger-friendly AI prompt generator with a modern UI and extra productivity features.

## Features
- Topic-based prompt creation
- AI platform selection for ChatGPT, Claude, Gemini, Copilot, and General AI
- Multiple prompt categories: blog, SEO, social, marketing, email, business, study, coding, product, creative
- Tone, audience, language, length, and format controls
- Optional heading, example, and CTA toggles
- Random prompt generator
- Quick template buttons
- Save recent prompts with local storage
- Copy prompt button
- Download prompt as .txt
- Clear history feature
- Dark/light mode toggle
- Responsive layout for desktop and mobile
- Front-end only, no backend or API key needed

## Files
- `index.html` – complete tool and styling

## Blogger usage
1. Open Blogger dashboard.
2. Insert an HTML/JavaScript gadget or page.
3. Copy the full HTML from `index.html`.
4. Paste it into the Blogger editor.
5. Save and publish.

## Notes
- This tool works directly in the browser.
- It stores saved prompts in browser local storage.
- It does not require a server or AI API key.
